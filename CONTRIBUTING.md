# Panduan Kontribusi Tim

## Strategi Branching
Tim menggunakan GitHub Flow.

## Aturan Branch
1. Setiap anggota bekerja di branch masing-masing.
2. Format nama branch: tipe/deskripsi, contoh docs/profil-rjanah1.
3. Jangan mengubah main secara langsung.

## Konvensi Commit
Contoh: docs: tambah profil mahasiswa
Contoh: docs(anggota): lengkapi profil mahasiswa

## Aturan Kolaborasi
1. Setiap anggota menggunakan akun GitHub sendiri.
2. Perubahan ke main melalui Pull Request dengan satu persetujuan.
3. Dilarang menyimpan password, token, dan private key.
